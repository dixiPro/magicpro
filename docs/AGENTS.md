# Правила работы на этом сайте

Сайт работает на MagicPro — CMS поверх Laravel. Статьи, маршруты, вьюхи,
контроллеры, меню и настройки лежат в базе и правятся через админку, а не
файлами.

## Работать только через MCP

Всё, что нужно сделать с сайтом, делается инструментами MCP-сервера `magicpro`.

- Статьи читать `get-article`, `get-article-by-name`, `search-articles`.
- Статьи писать только `save-article`: он перегенерирует блейд и контроллер.
- Позицию в дереве менять только `move-article`.
- Файлы читать `read-file`, писать `save-file`.
- Ленты — `feed-api` и `feed-api-write`.

Нет подходящего инструмента — значит задача не решается, и об этом надо сказать.
Не искать обходной путь.

## Чего не делать

- Не писать в базу напрямую и не запускать миграции.
- Не трогать `composer`, `npm` и `git`.
- Не править файлы в `storage/dataMagicPro/`: они генерируются, правка пропадёт.
- Не удалять файлы и статьи без прямого указания.
- Не менять настройки сервера и права.

## Как отвечать

Коротко и по делу. Сперва сказать, что собираешься сделать, потом сделать, потом перечислить, что изменилось.

## Знак вопроса ?

Увидел в промпте знак вопроса ?, ничего не делай. Отвечай на поставленный вопрос.

## Выполнение

Считаешь задача может быть улучшена тогда задай вопрос, поясни свои предложения.
Иначе выполнить без улучшений, о которых не просили.
Предложения приветствуются.
Предложения не делаются без одобрения.

## Верстка товара

Контекст страницы:

- в верхней части страницы уже находится карточка товара;
- ниже размещается только текстовое описание товара;
- отдельный заголовок для описания не нужен.

Требования к верстке:

- используй простую семантическую HTML-разметку;
- главное читаемость текста для SEO;
- основные теги: `<p>`, `<strong>`, `<ul>`, `<li>`, при необходимости `<h2>` и `<h3>` для внутренних смысловых разделов;
- Bootstrap 5 уже установлен, можно использовать его стандартные классы только там, где это действительно улучшает читаемость;
- не создавай контейнеры, карточки, колонки, фоновые блоки и сложную декоративную верстку;
- не добавляй собственный CSS;
- не используй inline-стили;
- не добавляй `<html>`, `<head>`, `<body>`;
- не добавляй главный `<h1>`, так как название товара уже есть выше на странице;
- разбивай длинный текст на короткие абзацы;
- списки оформляй через `<ul><li>`;
- важные фразы можно выделять через `<strong>`;
- не меняй смысл исходного текста и не добавляй факты от себя;
- ссылки и кнопки добавляй только если они присутствуют в исходном тексте.
- не создавай контейнеры, карточки, колонки и декоративную верстку.

Верни только готовый HTML без пояснений и без Markdown-блока.
