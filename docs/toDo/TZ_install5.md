## методы проверки

для всет методов проверки

- пишут все сообщения в лог и успешные и нет.
- когда ошибка кладет ошибку в msgArr в формате markDowm выкидывает исключение.

`testCreateWriteDirectory(string absDir)` //

- проверяет наличие папки absDir, если нет создает папку, пишет туда тестовый файл удаляет запись, нет исключения

`testDirectory(string absDir)`

- проверяет наличие папки absDir.
- нет папки ошибки в msgArr в формате markDowm выкидывает исключение.

`checkAdmin()`

- проверяет пользователь рут нет выводит msgArr[] = `run magicpro:admin --email= --password=`

`checkArticles()`

- Проверяет Таблицу Артикл, если не ок, исключение `php artisan migrate`
- Проверяет есть ли рут статья id=1? если нет, создает, ошибка создания в `msgArr`
- Пишет в базу новую статью с именем текущее дата время, нет ошибка создания в `msgArr`, проверить создание контроллера и вью.
- Удаляет статью с именем текущее дата время, нет ошибка создания в `msgArr`, нет ошибка

`checkDirectories()`
Наличие директорий,прогоняет через `testCreateWriteDirectory` массив
['MAGIC_DATA_DIR', 'MAGIC_CONTROLLER_DIR', 'PUBLIC_UPLOAD_DIR', 'VENDOR_PUBLIC' 'STATIC_HTML_CREATE_DIR']

через `testDirectory` ['VENDOR_FROM']

сюда добирается, если все ок, если нет

`checSimLink()`

- проверить симлинк, не только наличие но и правильность.

`checkAssests()`

- проверяет наличие ассестов, нету — копирует, ошибка выбрасывает исключение
- версию берёт из `VENDOR_PUBLIC/version.txt` и сравнивает с `MAGIC_VERSION` (`src/Config/version.php`). Не совпало — копирует `readyBundle` заново и переписывает `version.txt`

## Правки вне инсталлера

Отдельные задачи, в класс не входят.

- `create_magicPro_users_table.php`: убрать `readline()` и печать пароля в
  консоль. Миграция только создаёт таблицу. Сейчас неинтерактивный
  `migrate --force` заводит админа с пустым паролем.
- `create_magicPro_articles_table.php`: у `root` и `error404` положить полный
  `routeParams`, как у `index`. Сейчас там `{}`.
- `admin/views/artList.blade.php`: нет ключа `useController` — это `false`,
  обычная статья. Ошибка — только если `routeParams` не разобрался в массив, и
  подсказка своя, про параметры маршрута, а не про контроллер.
- Команда `magicpro:admin --email= --password=` — её ещё нет, а `checkAdmin()`
  на неё ссылается. Спрашивать значения только при живом терминале, пароль не
  печатать.
