# Разработка MagicPro

Этот раздел — для разработчика, который создаёт новые решения в пакете,
исследует его механизмы и находит ошибки в коде.

## Граница работы

Админ верстает и программирует конкретный сайт в статьях. МСП-агент выполняет
задачи сайта через инструменты. Оба используют существующие механизмы MagicPro
и читают [mainUse](../mainUse/about.md).

Разработчик меняет эти механизмы: модель статьи, сохранение, генерацию,
маршрутизатор, редактор, MCP-инструменты и интеграции модулей. Например,
контроллер каталога в статье — использование; новый параметр маршрутизации
в модели, редакторе и обработчике URL — разработка пакета.

Продукт расположен в `packages/dixipro/magicpro`. Пути к исходникам в этом
разделе указаны относительно каталога пакета. Корневое Laravel-приложение
служит хостом; сгенерированные файлы в его `storage/dataMagicPro/` являются
результатом работы системы.

или комментарий о прежнем поведении.
