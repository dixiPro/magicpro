# AWS: назначение

Настройка почты Amazon — SES и SNS — консольными командами, без хождения по
консоли AWS.

## Что они делают

Три команды над двумя ini-файлами:

| Команда | Что делает |
| --- | --- |
| `magicpro:aws-setup` | «сайт может слать письма»: IAM-пользователь, права, ключ, SMTP-пароль |
| `magicpro:aws-webhook` | «сайт узнаёт, что с письмами стало»: топик, подписка, набор конфигурации с событиями |
| `magicpro:aws-status` | показывает, как всё настроено сейчас; ничего не меняет |

Граница между первыми двумя — по смыслу, а не по числу шагов. Топик, подписка и
набор конфигурации существуют ради одного: рассказать сайту, что случилось с
письмом. Сайту, которому это не нужно, хватает одной первой команды — письма
уходят и без всего остального.

Первая нужна раз на сайт, вторая — когда нужны события и при каждом переезде,
третья — когда непонятно, что происходит.

## Чего они не делают

Не подтверждают домен и адрес: это записи в DNS, их публикует человек. Команда
только проверяет, что подтверждение уже есть.

Не выводят аккаунт из песочницы — это заявка в поддержку AWS.

Не правят `.env_mpro`: боевой `.env` правит человек, команда лишь готовит блок
для копирования.

Не шлют тестовое письмо. Отправка — отдельная задача, ей нужны ключи, а хранить
их негде.
