# Создание AWS ключа с AdministratorAccess

### Создать IAM User

Открыть:

`IAM → Users → Create user`

Имя пользователя, например: `magicpro-setup`

Галку: `Provide user access to AWS Management Console` не ставить.

> Next

`Attach policies directly`

из списка внизу выбрать `AdministratorAccess`

> Next
> Create user

Вверху будет `View user`

> Create access key

`Command Line Interface (CLI)`

> Create access key

Access key и Secret access key сохранить их показывают один раз
