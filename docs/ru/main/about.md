# Центральный модуль: назначение

Статьи, маршруты, блейды и контроллеры. То, из чего состоит сам сайт.

## Что он делает

Одна статья — это сразу страница, маршрут, пункт меню и узел структуры. Имя
статьи становится адресом, тело — блейдом, рядом может лежать контроллер.
Сохранили статью в админке — на диск легли готовые файлы Ларавела, и страница
работает. Ни маршрутов, ни вью руками не создают.

Отсюда и остальное: дерево статей — это меню и хлебные крошки, флаг `isRoute` —
наличие адреса, `routeParams` — что этому адресу разрешено.

## Что сюда не входит

| Что                                               | Где                |
| ------------------------------------------------- | ------------------ |
| данные таблицами: цены, новости, каталоги         | `docs/ru/feed/`    |
| уменьшение картинок и кеш производных             | `docs/ru/image/`   |
| отправка писем, очередь, SES                      | `docs/ru/mail/`    |
| `MproHelper`: дерево, почта, телеграм, шифрование | `docs/ru/helpers/` |

## Что читать

`use.md` — если пишете страницу: поля статьи, параметры маршрута, конструкции
блейда, виды контроллеров.

`inside.md` — если правите сам модуль: путь запроса, генерация файлов, настройки,
главная админки.
