# Почта: назначение

Отправка писем с историей, очередью и повторными попытками.

## Что она делает

Письмо можно отправить сразу или отложить. В обоих случаях у него появляется
строка в базе — вместе с темой, телом, сырым MIME и историей ошибок. Дальше
судьбу письма видно на экране админки: ушло, ждёт очереди, ретраится, отвалилось
насовсем.

Отложенные письма разбирает крон, раз в минуту. Не ушедшее письмо не теряется:
оно получает следующую попытку по нарастающему интервалу, а когда попытки
кончились — статус `failed` и полный список ошибок в своей строке.

## Из чего состоит

| Что | Где |
| --- | --- |
| команды: отправить, отложить, разобрать очередь, списки, удаление | `src/Mail/API_Mail.php` |
| диспетчер команд, общая форма ответа | `src/Mail/AbstractMailApi.php` |
| приём событий SES через SNS | `src/Mail/AwsHookHandler.php` |
| письмо | модель `MagicProMailMessage` |
| адрес и блокировка | модель `MagicProEmailAddress` |
| короткий вход для страниц | `MproHelper::sendMail()` |
| экран админки | `/a_dmin/mailSystem` |

Транспорта два: обычный SMTP и Amazon SES API v2. Выбор — переменной окружения,
код вызова одинаковый.

## Чего она не делает

Не собирает письма из шаблонов: html приходит готовым. Не рассылает по спискам —
это отправка по одному адресу, список строит вызывающий. Не хранит вложения.

## Что читать

`inside.md` — если правите саму подсистему: статусы, ретраи, транспорты, вебхук.
