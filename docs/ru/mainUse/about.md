# Использование MagicPro

Этот раздел — для тех, кто делает сайт средствами готового MagicPro.
Программирование PHP-контроллера статьи относится к использованию системы.

## Три участника

| Участник | Задачи | Где работает |
| --- | --- | --- |
| Админ | Верстает и программирует сайт: страницы, шаблоны, компоненты, контроллеры, меню и данные | Админка, редактор статей и интерфейсы модулей |
| МСП-агент | Выполняет поручения по тому же сайту через доступные инструменты | MCP-сервер MagicPro и документация из `list-docs` |
| Разработчик MagicPro | Создаёт новые решения в пакете, изучает код и исправляет ошибки механизмов | Исходники пакета; раздел [mainDev](../mainDev/about.md) |

Это участники работы над проектом, а не перечень ролей авторизации в базе.
Админ здесь умеет писать код сайта; разработчик меняет саму систему.
МСП-агент работает в пределах инструментов и прав своего подключения.
