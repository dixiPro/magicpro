# Статические HTML-страницы

Раздел «Паук» (`/a_dmin/crawler`) умеет снять HTML-копию сайта:

1. Берёт дополнительные начальные адреса из `RENDER_URL`.
2. Заходит на них и на `/` от имени сервера.
3. Следует по найденным ссылкам, проверяет также внешние ссылки.
4. Сохраняет текстовые страницы текущего домена во временный каталог
   `storage/app/private/magic/html`.
5. По команде публикации очищает каталог `STATIC_HTML_DIR` и копирует туда
   подготовленные файлы.

Обычные адреса с точкой не сохраняются, если их явно нет в `RENDER_URL`.
Redirect не обходится, запрос ограничен коротким таймаутом.

Отдаёт файлы nginx, раньше php; нужные строки `try_files` — в
[настройке nginx](../mainDev/install.md#nginx). Успешная публикация файлов
или удаление статьи снимает
её копию (`html/<имя>.html` и `html/<имя>/`), и до следующей публикации страница
идёт через php. Запечь заново — снова пройти сайт и опубликовать.

Если сохранение вернуло `warning`, публикация и снятие копии не выполнялись.
Страницы, которые включают изменённый шаблон, меню или компонент, автоматически
не снимаются: после таких изменений нужен новый обход и публикация зависимых
страниц. Query string не входит в имя статического файла; разные query-варианты
одного пути не получают отдельных HTML-копий.
