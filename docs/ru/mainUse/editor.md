# Редактор, дерево, архив версий

## Дерево и редактор

В дереве по правой кнопке доступны:

- создание дочерней статьи;
- открытие в новой вкладке;
- копирование одной статьи без её детей;
- вырезание и вставка под другого родителя;
- экспорт статьи вместе с поддеревом;
- удаление статьи вместе с поддеревом.

Перетаскивание меняет порядок только внутри текущего родителя. Для переноса под
другого родителя используйте вырезание и вставку.

Полезные клавиши редактора:

- `Ctrl+S` — сохранить;
- `Alt+1` — открыть статью, имя которой выделено в редакторе;
- `Alt+/` — добавить или снять Blade-комментарий у выбранных строк.

Лампочка открывает заготовки контроллеров. Кнопка архива показывает версии
текущей статьи. Меню с полосками открывает параметры маршрута.

## Архив версий

Каждое фактическое изменение через `saveById` оставляет полную JSON-копию
сохранённой статьи. Повторное сохранение без изменений новую версию не создаёт.

- срок хранения задаёт `ARCHIVE_DAYS`, стандартно 30 дней;
- `0` означает хранить без срока;
- самая свежая версия статьи не удаляется автоматической чисткой;
- последняя версия удалённой статьи сохраняется; более старые версии могут
  попасть под очистку по сроку, все оставшиеся можно удалить вручную на Setup;
- восстановление является новым обычным сохранением и снова генерирует файлы;
- импорт дерева архив версий не наполняет.

## Результат сохранения

Сохранённый исходник и опубликованная страница могут различаться. Если проверка
контроллера не прошла, API сохраняет текст и возвращает `warning`, а рабочие
файлы оставляет прежними. Исправьте указанную ошибку и сохраните статью снова.
При новом имени прежние файлы не обслуживают автоматически новый адрес.

Подробности — [сохранение и публикация](use.md#сохранение-и-публикация-статьи).
