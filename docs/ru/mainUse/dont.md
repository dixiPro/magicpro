## Вызов хелперов из кода сайта

Не подставляйте непроверенное значение запроса в имя лога, ключ шифрования,
токен бота или имя документа. Выбор этих значений относится к коду сайта.
Не предполагайте, что все методы одинаково перехватывают исключения:
границу каждого метода смотрите в [справочнике](../helpers/use.md).
`dump`, `feedText` и готовый HTML выводите с учётом происхождения содержимого.
