# Агент для сайта: установка на Windows

В архиве всё, чтобы Claude Code или Codex работали с этим сайтом через МСП.
Адрес сайта уже вписан.

## Что нужно заранее

Установленный Claude Code или Codex — тот, которым будешь пользоваться.

## Установка

1. Распакуй `install.zip` в любую папку, например `L:\projects\site-mcp`.
   Это будет папка агента: он работает из неё и читает оттуда свои правила.
2. На странице MCP в админке сайта нажми «Получить токен» и скопируй его.
3. Запусти `runClaude.bat` или `runCodex.bat` — что у тебя установлено.
4. Введи токен.
5. При первом запуске:
   - Claude Code спросит, подключать ли сервер `magicpro` из `.mcp.json`, — да;
   - Codex спросит, доверять ли папке, — да: иначе он не прочтёт
     `.codex/config.toml`.

## Каждый следующий раз

Запусти `.bat` и введи токен. Продолжить прошлый разговор —
`runClaudeContinue.bat` или `runCodexContinue.bat`.

## Что в папке

| Файл | Зачем |
| --- | --- |
| `runClaude.bat`, `runCodex.bat` | спрашивают токен и запускают агента; токен живёт только в этом окне |
| `runClaudeContinue.bat`, `runCodexContinue.bat` | то же, но продолжают прошлый разговор |
| `.mcp.json` | адрес МСП для Claude Code |
| `.codex/config.toml` | адрес МСП для Codex |
| `AGENTS.md` | говорит агенту прочитать правила работы с сайта, через МСП |
| `CLAUDE.md` | говорит Claude Code прочитать `AGENTS.md` |

Токен ни в один файл не записывается.
