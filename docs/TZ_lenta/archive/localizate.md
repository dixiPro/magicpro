# Локализация админки

Что осталось по-русски при переключении админки на английский. Структура и данные
уже переводятся, ниже — то, что мимо словаря.

Словарь фронта: `admin/js/app/CommonCom/translate.js` (ru / en, вызов `t()`).
Язык берётся из `MagicGlobals::$INI['LANGUAGE']`.

## 1. Билдер лент

`admin/js/app/feedAdmin/feedBuilder.vue`

Названия рецептов:

- Запись по id
- Создать запись
- Изменить запись по id
- Удалить запись по id
- Билдер списка

Заголовки конструктора: «Условия», «Сортировка», «Пагинация», «по N записей на
странице».

Подписи системных полей в списках выбора: `видимость`, `дата создания`,
`дата изменения`.

Текст внутри генерируемого кода: «Запись не найдена», «Запись создана»,
«Запись изменена», «Запись удалена», «Лента не найдена», «Записей нет»,
`'значение'`, `'да' : 'нет'`, `['ключ' => 'значение']` и комментарии в примерах.

## 2. Список записей

`admin/js/app/feedAdmin/dataImageField.vue` — «МБ» и «КБ» в размере файла.

## 3. «Выберите файл» / «Файл не выбран»

Это не наш текст. Так родной `<input type="file">` подписывает себя сам, язык
берёт из браузера, а не из админки. Словарём не лечится: нужно прятать сам input
и рисовать свою кнопку с подписью.

## 4. Старый редактор статей — сделано

Тексты переехали в `translate.js` под префиксом `art_`. В `Tree.vue`,
`AceEditor.vue` и `FindText.vue` заодно подключён `useI18n`, раньше его там не
было.

Было:

- `ArtEditor/component/TreeArticle.vue` — «Вырезано», «Вставлено», «Создано»,
  «Удалено», «Скопировано», «Удалить ?», «Не стоит удалять root», ошибки удаления
- `ArtEditor/component/Tree.vue` — «Ошибка перетаскивания»
- `ArtEditor/component/AceEditor.vue` — «Статья не выделена»
- `ArtEditor/component/Help.vue` — заголовок «Справка»
- `ArtEditor/component/FindText.vue` — placeholder «найти»

## 5. Сервер — сделано

Тексты переехали в словарь пакета, `lang/ru/messages.php` и `lang/en/messages.php`,
префикс `feed_err_`. В коде остались ключи: `API_Feeds::err('feed_not_found')`,
в моделях — `MagicLang::getMsg(...)`. Неизвестный ключ отдаёт сам ключ, чтобы
пропажа была видна.

Было:

- `src/Lenta/API_Feeds.php`, массив `ERRORS` — около сорока строк, от «Лента не
  найдена» до «Связи замыкаются в кольцо»
- `src/Lenta/FeedValidationException.php` — «Проверьте заполнение полей»
- `database/Models/FeedItem.php` — «На запись ссылаются, она не удаляется»
- `database/Models/FeedGroup.php` — «Группа по умолчанию не удаляется», «В группе
  есть ленты, она не удаляется»
- `admin/js/app/apiCall.js` — «Ошибка сети», «Невалидный ответ», «Неизвестная
  ошибка». Переведено через `translate.js`, префикс `api_`: это фронт, словарь у
  него свой

Названия новых группы и ленты тоже из словаря (`feed_new_group`, `feed_new_feed`).
Заголовок пишется в базу на языке, который стоял в момент создания, и дальше
живёт как данные — оператор переименовывает его сразу.

## 6. Сообщения валидатора Laravel

Тексты правил берутся из локали приложения, а не из словаря админки. Ошибка про
пять символов придёт на языке приложения.

Генерируемый код билдера — весь на английском и на русский не переводится: и
комментарии, и то, что код выводит на страницу («Record not found», `'yes' : 'no'`,
заготовки `'value'`).

Язык один на установку, из настроек. Переключателя для пользователя не будет,
поэтому сервер читает язык один раз за запрос и не возит его в ответах.
