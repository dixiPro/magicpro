## Билдер

$items = Feed::where('code', 'trenings')->first()?->items() // лента trenings или null + её записи + её схема
// условиея
->where('\_\_visible', true) // скрытые не показываем
// сортировка  
 ->orderByDesc('created_at') // новые сверху
// пагинация  
 ->paginate(20, ['*'], 'page', $page);
@endphp

Разбиваем страницу

Это всегда фиксировано

$items = Feed::where('code', 'trenings')->first()?->items()

Условия

- выбираем поле в списке, например title
  появляется

1. = 'значение'
2. like 'значение'

выбираем 1, запрос становится

$items = Feed::where('code', 'trenings')->first()?->items()
->where('title', '=', 'значение')

Условия соединяются только через AND. Групп и скобок нет.

Условий может быть несколько, идут подряд, в том порядке, в котором их добавил
оператор.

$items = Feed::where('code', 'trenings')->first()?->items()
->where('title', 'like', 'значение')
->where('price', '>', 100)

В условиях пишется code поля, физическое имя колонки оператор не видит и не
вводит.

### Сравнения по типу поля

- строка: `=`, `like`
- число: `=`, `<>`, `>`, `>=`, `<`, `<=`
- дата: `=`, `<>`, `>`, `>=`, `<`, `<=`
- boolean: `=` true / false
- связь: `=` id записи

`like` билдер пишет сразу с процентами

->where('title', 'like', '%значение%')

### Значение

Всегда литерал 'значение'. Что там будет на самом деле, билдер не знает —
дописывает оператор.

## Сортировка

Полей может быть несколько, идут в том порядке, в котором их добавил оператор,
у каждого своё направление.

->orderBy('title')
->orderByDesc('created_at')

## Видимость

Всегда в запросе.

->where('\_\_visible', true)

## Пагинация

Всегда, по 20 записей на странице.

->paginate(20, ['*'], 'page', $page)
