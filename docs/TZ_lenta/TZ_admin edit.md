### Примеры validation

Поле `validation` — свободный текст, строка правил Laravel. Что оператор написал, то и
уедет в схему; разбирать её будет штатный валидатор при сохранении записи.

| Что нужно                           | Строка                                 |
| ----------------------------------- | -------------------------------------- |
| Обязательная строка, 3–255 символов | `required\|string\|min:3\|max:255`     |
| Необязательный текст                | `nullable\|string\|max:5000`           |
| Обязательное целое в диапазоне      | `required\|integer\|min:100\|max:1000` |
| Почта                               | `required\|email`                      |
| Дата или дата-время                 | `required\|date`                       |
| Флаг                                | `required\|boolean`                    |
| Одно из значений                    | `required\|in:new,used,broken`         |
| По маске                            | `required\|regex:/^[A-Z]{2}-\\d{4}$/`  |

Правила пишутся через `|`, порядок значения не имеет. `required` — часть той же строки,
отдельного ключа под него нет. `nullable` нужен, чтобы пустое значение не считалось
ошибкой.

Уникальность правилом Laravel не задаётся — для неё есть отдельная колонка `Unic`: слот
общий для всех лент, и `unique:magicPro_feed_items,__string_2` проверял бы всю таблицу.

Полный список правил — в документации Laravel:
<https://laravel.com/docs/validation#available-validation-rules>

Эти же примеры показывает подсказка «?» рядом с заголовком группы.
