# Установка

## windows

Создай в виндах папку

```
l:\проекты\solnuhMcp
```

Скопируй в l:\проекты\solnuhMcp все файлы из папки settings. Саму папку не копируй. Просто файлы
Скопируй в l:\проекты\solnuhMcp все файлы из папки runWindow. Саму папку не копируй. Просто файлы

- Запусти runCodex.bat или runClaude.bat что у тебя установлено.
- Он спросит токен - введи любое число, например 123.
- Агент будт ругаться у него не настроен адрес mcp сервера.
- После того как он поругается дай команду
- **выполни first.md**
- Агент запросит адрес MCP . Возьми его на сайте в разделе /admin/mcp/. Адрес будет вида https://САЙТ/api/mcp/rpc
- Скажи адрес агенту, он сам впишет куда надо.
- Закрой агента.
- Запусти заново.
- Введи валидный ключ.

## linux

Как для windows, только вместо runWindow — runLinux.
