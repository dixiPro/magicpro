# Работа с сайтом

Всё делается инструментами MCP-сервера.

МСП Солнух — MCP-сервер статей модуля «Дизайн». Транспорт Streamable HTTP, авторизация `Authorization: Bearer <токен>`. Токен приходит **только** из переменной окружения `SOLNUH_TOKEN`.

## Чего не делать

- **Не удалять без подтверждения или молча.** удаление статьи удаляет не только статью но и всю ветку под ней.
- **Если нужно удалить статью** обязательно спроси можно ли это сделать. Предупреди содержит ли статья потомков.
- **Не переименовывать статью без необходимости.** Имя это адрес: сменил имя — сломал ссылки и поисковую выдачу.
- **Не искать обходных путей.** Нет подходящего инструмента — задача так не решается, так и скажи.
- **Не улучшать по дороге.** Просили поправить кнопку — правь кнопку, а не вёрстку вокруг неё. Видишь, что рядом плохо, — скажи словами.

## Как отвечать

Коротко. Сперва что собираешься сделать, потом делаешь, потом перечисляешь, что
изменилось: какие статьи и файлы.

- **Вопрос — это не задача.** Спросили — ответь и остановись. «Как лучше сделать X?» не означает «сделай X». Увидел в запросе знак вопроса отвечай, а не делай.
- Не уверен, что понял задачу, — спроси до того, как начал править.
- Увидел в промпте знак ? это вопрос, надо ответить

## Работа со статьями

Статьи — дерево от `root`, адресуются по `name`. Действия идут от имени выдавшего токен,
с его правами в «Дизайне». Сохранение статьи выполняет PHP на сервере.

1. Перед правкой — `get-article`, правку строить от того, что вернулось.
2. `save-article` требует `name`, `title`, `body`, `template`. После — смотреть `parseError` и `warning`, при ошибке исправить тело и сохранить снова.
3. PHP в теле — только многострочными блоками: однострочный `<?php … ?>` при сохранении вырезается (`removedInlinePhp`).
4. Дерево меняется только через `move-article`.
5. Удаление — в два шага: `delete-article` с `confirm=false`, показать список человеку, после его согласия `confirm=true`.
6. Синтаксис шаблонов, ViewHelper-функции и API сайта — `get-template-manual`, `get-view-helpers`, `get-api-resources`. Не угадывай, читай.
7. PHP, в который транслировалась статья, — `get-article-php`. Только чтение, для поиска ошибок.
8. Блоки {[имя]}…{[/имя]} статьи транслируются в отдельные PHP-файлы: `get-article-php` с `template`.

## Если что-то сломал

Каждое сохранение статьи попадает в архив версий. Откатить может человек: в редакторе статьи кнопка с архивом, там список версий и «восстановить». Сообщи, что сломал и когда, — этого хватит, чтобы найти нужную версию.

## Ошибки 401

| Ответ                                                    | Причина                                                |
| -------------------------------------------------------- | ------------------------------------------------------ |
| `no token`                                               | нет `SOLNUH_TOKEN`: сессия запущена не через лаунчер   |
| `unknown token`                                          | токен отозван или заменён новым — нужен новый          |
| `the token was issued for another address`               | IP агента не совпадает с IP браузера: VPN, прокси, WSL |
| `the token expired: an hour without calls`               | час без запросов — нужен новый                         |
| `the token expired: a day from the issue`                | прошли сутки — нужен новый                             |
| `the owner of the token has no access to the mcp module` | у пользователя отобрали права на модуль mcp            |

На любой из них — остановиться и попросить человека выдать новый токен и перезапустить лаунчер.
