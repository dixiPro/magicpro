Потом всегда кроппер

## Три сценария использования

### В движке

Выбираем, настраиваем, нажимаем далее
Движок спрашивает имя файла и в каком формате и качестве, например авиф вебп

### В ленте

Выбираем, настраиваем, нажимаем далее
Движок спрашивает имя файла форматы определены

### В магазине

Выбираем, настраиваем, нажимаем далее
Движок ничего не спрашивает, имя и форматы определены

## Решено

1. **Компонент независим.** Сам читает файл, сам читает буфер обмена, сам
   обрабатывает и отдаёт готовые файлы. Что с ними делать — забота хозяина.
2. **Кропер — `vue-advanced-cropper`**, свой писать не будем.

3. **Локализации нет:** подписи одним блоком в файле компонента.
4. **Иконки — потом**, отдельными файлами в `src/assets/icons/`.
5. **Отдаёт два файла:** `original` — то, что прочитали, и `cliped` —
   обрезанное. Не обрезали — ключа `cliped` в ответе нет.
6. **Оригинал отдаётся всегда.** Многим нужно хранить и его, и обработанное,
   чтобы потом обработать заново.
7. **Кнопка «Сохранить» своя.** Есть слот — работает слот, нет — стоит кнопка
   компонента.
8. **Подачи файла снаружи нет:** ни `v-model`, ни методов. Только выбор файла и
   буфер внутри компонента, наружу — `save`.
9. **После `save` компонент очищается.**
10. **Событие одно — `save`.** `loaded`, `cancel`, `clear` пока не нужны.
11. **Живёт внутри MagicPro** (`admin/js/magic-image/`), собирается отдельно;
    песочница собирается в `public/magic-image/` — только для проверки. Позже
    папка уедет в свой репозиторий, магазин заберёт `src` сам.

## Как вызывается

```vue
<MagicImage
  :min-x="600"
  :min-y="600"
  ratio="16/9"
  format-clipboard="image/webp"
  :quality-clipboard="82"
  format-result="image/png"
  :quality-result="100"
  @save="onSave"
>
    <template #actions="{ canSave, apply }">
      <button v-if="canSave" @click="apply()">Сохранить</button> // важная кнопка, возможно хозяин захочет конвертнуть файл в какой то формат,можно написать продолжить
    </template>
  </MagicImage>
```

Минимальный вызов — только обработчик, всё остальное по умолчанию:

```vue
<MagicImage @save="onSave" />
```

## Пропсы

| Проп               | Тип    | Умолчание      | Что делает                                                  |
| ------------------ | ------ | -------------- | ----------------------------------------------------------- |
| `minX`             | number | `0`            | меньше по ширине не принимаем — ни исходник, ни обрезанное  |
| `minY`             | number | `0`            | то же по высоте                                             |
| `ratio`            | string | `'1/1'`        | если пусто можно любое                                      |
| `formatClipboard`  | string | `'image/webp'` | чем кодировать картинку из буфера: у неё нет файла          |
| `qualityClipboard` | number | `82`           | качество для буфера, 1–100                                  |
| `formatResult`     | string | `'image/png'`  | формат обрезанного: `image/png`, `image/jpeg`, `image/webp` |
| `qualityResult`    | number | `100`          | качество обрезанного, 1–100; для PNG не действует           |

Числа и булевы передаются с двоеточием (`:min-x="600"`), иначе прилетит строка,
а `"false"` — это истина.

## Событие `save`

```js
function onSave({ original, cliped }) {
  // original: { file, width, height, format }
  // cliped:   { file, width, height, format } — только если обрезали
}
```

- `file` — готовый `File` с именем и расширением по формату.
- имя файла зашито жестко. original для оригинала и crop для кропа.
- `original` — то, что прочитали: выбранный файл уходит как есть, картинка из
  буфера кодируется по `formatClipboard` и `qualityClipboard`.
- `cliped` — обрезанное, в `formatResult`. Не обрезали — ключа нет.

## Слот

```vue
<MagicImage @save="onSave">
  <template #actions="{ canSave, apply }">
    <button v-if="canSave" @click="apply()">Сохранить</button>
  </template>
</MagicImage>
```

Слота нет — компонент рисует свою кнопку «Сохранить». `canSave` — размеры
проходят по `minX` и `minY`, имя введено, если его требуют.

## Что компонент делает сам

- читает файл и буфер обмена;
- показывает размеры и не даёт сохранить то, что меньше `minX` и `minY`;
- яркость, контраст, насыщенность, уровни с гистограммой, резкость;
- кроп с пропорцией или свободный;
- кодирует результат, собирает `File` с именем и расширением;
- очищается после `save`.

## Чего компонент не делает

- не ходит на сервер;
- не проверяет имя файла — это забота хозяина;
- не знает, куда и в каком виде положат результат;
- не принимает файл снаружи.
