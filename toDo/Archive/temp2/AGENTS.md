# CLAUDE.md

This repository exists for one product — **MagicPro**. All development happens inside the
package:

`packages/dixipro/magicpro`

The root Laravel 13 application is only a host for it, connected through a symlinked Composer
path repository.

## Прочитай перед любой правкой кода

Открой `packages/dixipro/magicpro/docs/ru/claudeRules/rules.md` и следуй ему. Это не
справка, а порядок работы: что делать без спроса, чего не трогать никогда, чем проверять
сделанное, как отвечать.

Пока не прочитал — держи в голове хотя бы это:

- вопрос — это не задача: спросили, значит ответь и ничего не делай;
- без разрешения не лезь в базу, в git и в composer;
- отвечай по-русски, код и комментарии пиши по-английски.
