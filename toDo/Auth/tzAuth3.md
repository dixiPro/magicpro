В админке, на странице модуля

```json
{
  "authUrl": "/auth", //  cтраница регистрации
  "postUrl": "/newProduct", // страница  после регистрации или авторизации
  "authLetter": "auth_registerLetter", //имя блейда письма для подтверждения емайла
```

`Alpine.js`

## apiAuth POST

Как во всем пакете

apiAuth (command, params)

command:

- checkEmail - проверяет емайл на валидность и на то есть в базе или нет)
- registerUserByToken - регистрирует по токену
- sendRegisterEmail - высылаем регистрационное письмо
- auth - авторизуем юзера
- sendChangePasswordEmail - высылаем письмо смены пароля
- changePassword - меняем пароль

## Страница регистрации

Для сайта одна страничка, задается в настройках в админки. Страница регистрации работает в нескольких режимах

### Форма регистрации параметров нет

Выводится форма регистрации

[ Ваш емайл ] <готово>

```js
{
  "command": "checkEmail",
  "params": {
    "email": email,
    "gToken": token
  }
}
```

Возврат

```js
{
  "status": "1", // или 0
  "errorCode": "0", // код ошибки
  "errorMsg": "", //
  "emailToken": "smkadfoadf", // шифрованный емайл+ время создания
  "emailActive": "false" // есть ли такой емайл в базе
}
```

#### Емайла нет

Емайла нет регистрировать? (тык появляется)

[ Введите пароль ] <готово>

```js
{
  "command": "sendRegisterEmail",
  "params": {
    "emailToken": emailToken, // получили с сервера
    "password": password
  }
}
```

Возврат

```js
{
  "status": "1", // или 0
  "errorCode": "0", // код ошибки
}
```

Идите на емайл там письмо
Ветка закончилась

#### Емайл есть

```js
  "emailActive": "true" // есть ли такой емайл в базе
```

[ введите пароль ] <готово>
забыли пароль?

```js
{
  "command": "auth",
  "params": {
    "emailToken": emailToken, // получили с сервера
    "password": password
  }
}
```

Если все ок переадрессация на `postUrl`

##### Забыли пароль

Забыли пароль (тык)
Выслать парольна емелй (да)

```js
{
  "command": "sendChangePasswordEmail",
  "params": {
    "emailToken": emailToken, // получили с сервера
  }
}
```

### Регистрация по токену парамер mode/regByToken/token

- зовет registerUserByToken(token), если ок, авторизует, шлет `postLetter`, редирект на `postUrl`

### Восстаовление пароля парамер mode/changePassword/token

- принимает новый пароль, затем зовет changePassword(token,newPassword), если ок, авторизует, редирект на `postUrl`

## Форма регистрации

Может быть установлена модалкой на любой странице.
Например
<x-magic::register_form postUrl="/newProduct"/>

Основное назначение регистрация без перенаправления на основную страницу. Юзер тык получить услугу, модалка, введите емайл дальше что пришлем, услугу, товар. Все без переходов.

В форме регистрации можно задать "postUrl": "/newProduct", // страница куда должны переадрессовать юзера после регистрации/авторизации.
