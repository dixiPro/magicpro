# Примеры писем

## Пример authLetter

```html
<p>Здравствуйте.</p>
<p>От вас, или от вашего имени, поступил запрос на сайте {{ request()->getHost() }}</p>
<p>Для подтверждения емайл <a href="{{ $authLinkUrl  }}">пройдите по этой ссылке →</a></p>
<p>Ссылка {{ $authLinkUrl }}</p>
<p>C уважением</p>
```

`$authLinkUrl` подставляет АПИ: адрес страницы `registerUrl` и токен. Клиент тыкает на ссылку и попадает на страницу `registerUrl` — не в API. Страница сама зовёт `registerUserByToken`: пользователь уже есть — тихо входит; нет — вводит пароль, заводится запись, клиент **авторизуется**, ему уходит письмо `postLetter`, переход на `postUrl`. Токен протух — форма входа и регистрации `authUrl`.

## Пример postLetter

`$userEmail` и `$userPassword` подставляет АПИ. Пароль выводить не обязательно — можно написать «пароль, указанный при регистрации».

```html
<p>Здравствуйте.</p>
<p>Вы зарегистировались на сайте {{ request()->getHost() }}</p>
<p>Ваш логин {{ $userEmail }}</p>
<p>Ваш пароль {{ $userPassword }}</p>
<p>C уважением</p>
```

## Пример resetPasswordLetter

`$authResetPasswordUrl` подставляет АПИ: адрес страницы `resetPasswordUrl` и токен.

```html
<p>Здравствуйте.</p>
<p>Вы запросили восстановление пароля на сайте {{ request()->getHost() }}</p>
<p><a href="{{ $authResetPasswordUrl }}">Пройдите по ссылке →</a></p>
<p>C уважением</p>
```
