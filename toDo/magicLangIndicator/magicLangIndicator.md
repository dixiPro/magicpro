# ТЗ: MagicLangIndicator

## Цель

Создать portable-программу для Windows, которая показывает текущую раскладку клавиатуры (`RU`, `EN`, `SR` и т.п.) рядом с текстовой кареткой ввода.

## Основные требования

- Язык: C#.
- Portable `.exe`.
- Без установки.
- Готовая self-contained сборка не должна требовать отдельно установленный .NET Runtime.
- Индикатор привязан только к текстовой каретке, не к мыши.
- Если текстовой каретки нет — индикатор скрыт.

## Поддерживаемые приложения

Приоритет:

- VS Code.
- Microsoft Word.
- Microsoft Excel.
- Microsoft powerPoint.
- Браузеры.
- Electron-приложения.
- Обычные Windows-поля ввода.

В Excel индикатор показывать только при реальном редактировании текста/формулы, а не при простом выборе ячейки.

## Определение каретки

Основной механизм:

```text
Windows UI Automation
→ TextPattern / TextPattern2
→ GetCaretRange()
→ BoundingRectangle
```

Fallback:

```text
GetGUIThreadInfo()
→ rcCaret
```

## Реакция на события

Программа должна работать преимущественно событийно:

- смена активного окна;
- смена focus;
- перемещение текстовой каретки;
- смена раскладки.

При смене раскладки надпись должна меняться сразу.

Допускается контрольная проверка состояния примерно раз в 1 секунду.

Не использовать постоянный polling с интервалом 50–100 мс.

## Индикатор

Пример:

```text
EN
```

или:

```text
RU
```

Окно индикатора:

- без рамки;
- always-on-top;
- не получает focus;
- click-through;
- прозрачный фон;
- маленький шрифт.

Позиция рассчитывается относительно каретки.

## config.json

Пример:

```json
{
  "offsetX": 10,
  "offsetY": 5,
  "fontSize": 10,
  "opacity": 0.8,

  "layouts": {
    "00000409": {
      "name": "US",
      "language": "English",
      "display": "EN"
    },
    "00000419": {
      "name": "Russian",
      "language": "Russian",
      "display": "RU"
    }
  }
}
```

Главное пользовательское поле:

```json
"display": "EN"
```

Его можно вручную изменить на любое значение.

## Раскладки

Не считать, что одному языку соответствует одна клавиатура.

Например, у английского могут быть:

- US;
- English International;
- Типографская раскладка Ильи Бирмана.

Поэтому конфигурация должна храниться по идентификатору конкретной раскладки Windows.

## Режим сканирования

Программа должна поддерживать:

```bash
MagicLangIndicator.exe --scan
```

Этот режим:

1. Получает список всех установленных в Windows раскладок.
2. Получает для каждой:
   - ID / KLID;
   - название;
   - язык.
3. Читает существующий `config.json`.
4. Добавляет отсутствующие раскладки.
5. Существующие записи не перезаписывает.
6. Автоматически предлагает `display`:
   - English → EN
   - Russian → RU
   - Serbian → SR
   - и т.п.
7. Записывает обновлённый `config.json`.
8. Завершается.

После этого пользователь при необходимости вручную редактирует поле `display`.

## Поведение при неизвестной раскладке

Если активной раскладки нет в `config.json`:

1. Попробовать определить язык.
2. Временно показать двухбуквенный код языка.
3. Не изменять существующий `config.json` автоматически во время обычной работы.

Добавление раскладок в конфиг выполняется через:

```bash
MagicLangIndicator.exe --scan
```

## Примеры запуска

Обычная работа:

```bash
MagicLangIndicator.exe
```

Обновить список клавиатур:

```bash
MagicLangIndicator.exe --scan
```

## Критерий готовности

Основной сценарий:

1. Открываем VS Code.
2. Ставим текстовую каретку в код.
3. Рядом появляется `EN` / `RU`.
4. Переключаем раскладку.
5. Надпись меняется сразу.
6. Перемещаем каретку.
7. Индикатор следует за ней.
8. Убираем focus из текстового поля.
9. Индикатор исчезает.

То же должно корректно работать в Word и при редактировании ячейки/формулы в Excel.
