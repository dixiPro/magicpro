## 1. Формы сайта без `@csrf` не защищены

**Где:** `admin/web.php` (catch-all вне CSRF middleware),
`DynamicRouteHandler::checkToken()`.

Сейчас токен проверяется, только если его прислали. Форма без `@csrf` проходит,
поэтому у каждой изменяющей данные статьи защита — на совести её контроллера.

Включить проверку для всех нельзя просто так, сломается:

- существующие формы без `@csrf` — 419;
- формы на запечённых страницах: в `public/html/` лежит токен сессии краулера,
  у посетителя другой — 419 даже с `@csrf`;
- внешние POST в статью (оплаты, вебхуки) — токена у них нет.

Варианты: флаг `csrfEnable` в `routeParams` у статьи, или проверка для всех
плюс список исключений. Решение за владельцем.
