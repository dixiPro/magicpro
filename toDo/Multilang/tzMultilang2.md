# ТЗ v2: многоязычный сайт на MagicPro

Основа — `tzMultilang.md` (варианты) и решения владельца. Здесь только
выбранное; то, что ещё не решено, — в «Вопросах» внизу.

## Решено

1. **Адрес — префикс языка, по стандарту Google:** `/en/about`.
2. **Язык — префикс в имени статьи:** `en__about`, `ru__about`, `fr__about`.
   Имя статьи по-прежнему одно поле, и оно же имя блейда
   (`magic::en__about`) и класса контроллера (`MagicProControllers\en__about`).
3. **Префикс обязателен в начале каждой статьи** многоязычного сайта.
4. **Список префиксов задаётся в админке** (`en__`, `ru__`, `fr__`). Имя не из
   списка, без префикса или с префиксом не по правилу — **ошибка сохранения**.
5. **Язык по умолчанию задаётся в админке.**
6. **Ленты — пока без изменений в движке.** Язык в ленте решает сайт: своё поле
   на язык или всё в `__data` (JSON).

## Почему `en__about`, а не `en/about`

Имя остаётся в нынешних правилах `^[A-Za-z0-9_-]+$`. Не меняются:

- проверка имени в роутере, сохранении, импорте, МСП (`get-article-by-name`);
- пути файлов: `view/en__about.blade.php`, `controller/en__about.php` — плоско,
  без подпапок;
- имя класса контроллера — допустимое имя PHP;
- `@include('magic::en__about')`, `<x-magic::en__button>`.

Меняется только связь «адрес ↔ имя» в роутере и проверка префикса при
сохранении.

## Как это работает

### Роутер (`DynamicRouteHandler`)

| Адрес                   | Статья                                     | Язык |
| ----------------------- | ------------------------------------------ | ---- |
| `/en/about`             | `en__about`                                | en   |
| `/en`                   | `en__index`                                | en   |
| `/en/product/red-chair` | `en__product`, дальше параметры как сейчас | en   |

1. Первый сегмент — код языка из списка → язык найден, сегмент снят, имя
   статьи = `<код>__<второй сегмент>` (`index`, если сегмента нет).
2. Язык в `App::setLocale()`, в `$Env['lang']` и в атрибуты запроса для
   контроллера.
3. Прямой адрес `/en__about` — 404, как сейчас `/robots___txt`: у страницы один
   адрес.

### Сохранение статьи

Многоязычный сайт (список префиксов не пуст):

- имя начинается с префикса из списка — иначе ошибка;
- после префикса — непустое имя;
- проверка одна для всех путей рождения статьи: редактор, кнопка «создать»,
  МСП, импорт, установка.

Одноязычный сайт (список пуст) — всё как сейчас.

### Что затронуто

| Где                                                         | Что сделать                                                                                                       |
| ----------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------- |
| Настройки                                                   | список префиксов языков, язык по умолчанию                                                                        |
| `DynamicRouteHandler`                                       | язык из первого сегмента, имя `<код>__<имя>`, `setLocale`, `$Env['lang']`, 404 на прямой `/en__about`             |
| Сохранение (`Article`, API статей, МСП, импорт, установщик) | проверка префикса                                                                                                 |
| Статика (`forgetStaticHtml`)                                | статья `en__about` → снять `html/en/about.html` и `html/en/about/`                                                |
| Паук                                                        | начальные адреса языков (`/en`, `/fr`)                                                                            |
| Хелперы                                                     | переключатель языка (эта страница на другом языке), `hreflang` для `<head>` — по имени: `en__about` ↔ `fr__about` |
| Дока, МСП-агент                                             | правило имён и префиксов                                                                                          |

## Ленты

Движок не меняется. Сайт выбирает сам:

- своё поле на язык: `title_en`, `title_fr` (строковые слоты — если по ним
  ищут, иначе `__data`);
- или все переводы в одном JSON-поле `__data`.

## Вопросы

1. **Общие статьи.** Шаблоны, include, компоненты, helper — тоже с префиксом?
   Тогда шаблон `main26` — это `en__main26`, `fr__main26` и т. д., копия на
   каждый язык. Или для общих статей нужен свой префикс (например, `all__`)?
2. **Язык по умолчанию в адресе.** `/about` открывает `ru__about` (основной без
   префикса), или у всех префикс: `/ru/about`, а `/about` — 404 или редирект?
3. **Главная `/`.** Статья основного языка (`ru__index`) или выбор языка по
   браузеру / куке с редиректом на `/en`?
4. **Служебные статьи.** `error404`, `robots___txt`, `sitemap___xml` —
   `en__error404` на каждый язык? `robots.txt` и `sitemap.xml` — по одному на
   сайт, с каким префиксом?
5. **Нет перевода.** `/fr/about`, а статьи `fr__about` нет: 404, основной язык
   или редирект?
6. **Тройное подчёркивание.** `___` сейчас значит точку (`robots___txt` →
   `/robots.txt`). Имя после префикса не может начинаться с `_`
   (`en___txt`) — так?
7. **Список префиксов.** «Жёстко» — это фиксированный список в коде пакета или
   список в настройках, куда админ может добавить `de__`? Что происходит со
   статьями, если язык из списка убрали?
8. **Переход существующего сайта.** Включили многоязычность — все статьи без
   префикса перестают сохраняться. Нужна команда «переименовать всё в
   `ru__`»? Ссылки внутри блейдов (`@include('magic::main26')`) она тоже правит?
9. **Регистрация.** `authUrl`, `registerUrl`, блейды писем — по одному набору на
   язык, или язык берётся из текущего адреса?
10. **Строки вёрстки** (кнопки, подписи в общих шаблонах, если шаблоны общие) —
    файлы Laravel `lang/`, лента «Переводы» или каждый язык в своей копии
    шаблона?
